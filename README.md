# ModDeck

**Game Trainers & Mods for PC** — the free, open alternative to WeMod.

Real game trainers powered by a local Companion app. No fake simulations, no BS.

## Features
- 🎮 Launch & mod your Steam/Epic/GOG games directly
- 🪙 Deck Points loyalty system — earn free months
- ⏱️ 5 free hours per game trainer
- 👑 Pro tier: unlimited time, 10x DP earning
- 🔌 ModDeck Companion: Cheat Engine-style memory editing

## Tech
Next.js 16 · TypeScript · Tailwind CSS

## Getting Started
\\\
npm install
npm run dev
\\\

The Companion app (Windows only) is required for real game functionality.
