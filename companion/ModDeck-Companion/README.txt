ModDeck Companion v0.1
======================

WHAT IT DOES
  Watches the games running on your PC. When it sees one of ModDeck's
  supported games, it beeps and shows  "GAME DETECTED"  — then you press
  [P] and your browser opens that game's trainer page on ModDeck.

HOW TO USE
  1. Double-click  start.bat
  2. Keep the little window open (that's the detector)
  3. Start any supported game — the window lights up
  4. Press  [P]  to jump into the trainer

  [O] = open ModDeck     [Q] = quit

MORE GAMES + REAL IN-GAME MODS
  The Mod AI on the site can build mods for any single-player game —
  the next Companion versions apply them directly to the game.

TROUBLESHOOTING
  - If Windows SmartScreen asks, click "More info" -> "Run anyway".
  - Nothing detects? Some games use odd process names — tell us the
    game and we'll add it.
